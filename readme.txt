A Joomla 5.x component gallery to create 3D perspective images from 2D images. 
You may add as many as images you would  like, you may set the gallery speed from the 
backsite component form. Better to make all images at the same width and length so that
You will have a better automatic gallery.
In Pro-version, you may stop the gallery , restart and other features from a panel under the gallery.
